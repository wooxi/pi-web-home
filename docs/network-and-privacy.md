# 网络与隐私

它连不连网、数据放在哪、以及为什么**不能**暴露到公网。

这个工具按**单机单人、无鉴权**设计，服务端默认绑定 `0.0.0.0`，即整个家庭局域网都能访问——这是为了手机/其他电脑能直接用，也因此**绝不能暴露到家庭路由器之外的任何网络**（公网、办公网）。上一条的 `Host`/`Origin` 校验挡住浏览器发起的跨源请求与 DNS rebinding，但**不是认证边界**。需要仅本机使用时设 `PI_WEB_HOME_HOST=127.0.0.1`。报告安全问题见 [SECURITY.md](../SECURITY.md)。

它会发起这些对外请求、并带有这些副作用；除版本检查外全部由你显式触发：

| 时机 | 目标 | 说明 |
|---|---|---|
| 启动时 | `https://pi.dev/api/latest-version` | 与 pi CLI 启动时轮询的同一个端点，只做版本比较（见 [更新提示为什么分两条路，而且都不代劳](./design-notes.md#更新提示为什么分两条路而且都不代劳)） |
| 点「获取可用模型」 | 你配置的 provider 地址 | 用 `GET <baseUrl>/models` 拉取模型列表 |
| 点 MCP 的「检查」 | MCP 配置里的命令或地址 | **会真的启动那个 stdio 命令**或请求那个 URL，超时 15 秒 |
| 与模型对话 | 你配置的 provider | 会话内容按 pi 的正常行为发给模型 |

除此之外，服务端不联网、不埋点、不上报。它读到的东西都留在本机：会话正文只有 pi 一份（`~/.pi/agent/`，或 `PI_WEB_HOME_SESSION_DIR` 指定的目录），项目记录与 UI 偏好在 `~/.pi-web-home/store.json`，模型的 API 密钥由 pi 自己管理（页面只写不读，见 [模型配置为什么在改文件](./design-notes.md#模型配置为什么在改文件)）。目录浏览（`/api/fs/*`）会枚举**服务端所在机器**的目录，但只列子目录名、不读文件内容。
